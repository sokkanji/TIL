# 정적 자산을 AWS private cdn에 올릴 때 장점과 주의할 점

## Private(서명 URL)로 만들면 좋은 점

- 무단 트래픽 차단 -> 비용 절감
  - 외부 스크래핑, 직접 링크로 인한 불필요한 데이터 전송 비용을 막을 수 있음
- 보안 강화
  - 내부 전용 파일, 유료 컨텐츠, 베타 버전 등 노출되면 안 되는 리소스 보호에 적합함
- 접근 통제 가능
  - 로그인한 사용자, 결제한 사용자 등 특정 조건을 만족한 사용자에게만 제공 가능

## Private로 전부 바꾸기 전 주의할 점

- 서명 URL 발급 로직이 필요
  - 정적 자산 하나하나에 대해 백엔드가 매번 서명 URL을 만들어줘야 함
- 캐싱, 배포 편의성 감소
  - URL마다 서명 파라미터가 달라지기 때문에 브라우저/Amazon CloudFront 캐시 히트율이 낮아질 수 있음
- SEO/공개 접근이 필요한 파일에는 부적합
  - 검색 엔진이 읽어야 하는 HTML 페이지, OG 이미지, robots.txt, sitemap 같은 파일은 공개로 유지를 해야 함
